🎮 NUMBER GUESSING GAME

OVERVIEW📌
A Java Console game where a player tries to guess a randomly generated number.The game
gives Too High, Too Low, OR Correct hint after each guess.

This project was created as par of the Oasis Infobtye Java Development Internship - Task 2.

FEATURES ✨
-
- Random number generation
- Too High/ Too Low hints
- Attempt counter
- Maximum attempts
- Input validation
- Play again option
- Score tracking across multiple rounds
- Difficulty modes
- Performance ratings

Difficulty Levels ✨
- 
-Easy mode, Range: 1 - 50, Attempts: 10
- Medium mode, Range: 1 -100, Attempts: 7
- Hard mode, Range: 1 - 200, Attempts: 5


Technologies 🛠️
-
 - Java
 - Scanner
 - Random
 - Console application

How to run task and Play▶️ 
-
1. Open the project in IntelliJ IDEA or another Java IDE
2. Run NumberGuessingGame.java
3. Choose the difficulty mode of your choice
4. Enter the guesses according to the max attempts you have.
5. Follow the hints to after each guess to marrow down your choices and get closer to the correct number.
6. Choose whether to play another round.

Scoring 📊
-
The game calculates the scores based on the selected difficulty and the number of attempts remaining.
The scores are added together across the multiple rounds played.
